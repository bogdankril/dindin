# **App Name**: GlassPro Manager

## Core Features:

- Dashboard Overview: Dashboard provides a summary view of jobs, customers, and inventory levels, enabling quick insights and actions.
- Job Scheduling: Manage and track all scheduled jobs, including customer and vehicle information, service type, date and time. Use a work day scheduler which allows user to go back and forward the list while excluding weekends.
- Customer Management: Maintain a customer database with contact details and service history for personalized service and communication.
- Inventory Tracking: Track inventory levels of glass and supplies, set reorder points, and manage stock efficiently to avoid shortages.
- Configuration Settings: Customize settings for business profile, job ID generation, and sales tax rates to tailor the app to specific business needs.
- VIN Decoder: Decode VIN to automatically fill vehicle details such as make, model, and year using an external API. The decoding "tool" attempts to reduce manual entry and improve accuracy.
- Work Order Preview: Generate a preview of the Work Order, to allow for review and modification before finalizing the job.

## Style Guidelines:

- Primary color: Deep sky blue (#3498db) to convey trust, reliability, and professionalism, relating to the sky and glass work.
- Background color: Very light gray (#f5f7fa) to create a clean, spacious interface, ensuring comfortable readability and focus on content.
- Accent color: A slightly lighter and more saturated sky blue (#5dade2) for interactive elements and highlights, drawing user attention to calls to action without being overpowering.
- Body and headline font: 'PT Sans' (sans-serif) provides a balance of modernity and readability.
- Use clean, geometric icons from a consistent set, primarily in the primary blue, to illustrate categories and actions within the app. Favor outline style over filled for a lighter feel.
- Implement a clear, card-based layout with ample spacing and subtle shadows to improve information hierarchy and user focus. Use consistent padding and margins to create a balanced appearance.
- Incorporate subtle transitions and animations, like fading content, to confirm actions, providing a polished and professional user experience, especially when navigating the interface.
